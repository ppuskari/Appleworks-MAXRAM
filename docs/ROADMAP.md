# Appleworks-MaxRAM Roadmap

## Phase 0 - Baseline

Reproduce stock AppleWorks memory behavior.
Reproduce Hugh Hood's extended Aux-memory implementation.

## Phase 1 - AUX16

Extend RamWorks-compatible auxiliary memory toward 16 MB.

## Phase 2 - SLINKY16

Extend RamFactor/Slinky memory toward 16 MB.

## Phase 3 - MAXRAM

Investigate simultaneous Aux and Slinky memory as one AppleWorks desktop.

## Phase 4 - AppleWorks 4.x

Port proven changes to supported AppleWorks 4.x revisions.
